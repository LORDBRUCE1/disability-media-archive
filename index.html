The project

A library of ways of seeing.

The Disability Media Archive examines how different stories make disability visible — or invisible. Each artifact is an invitation to ask how narrative, genre, geography, and the perspective of the storyteller shape representation.

The two readings in each entry are deliberate: Representation identifies one interpretation, while Read against asks what the first interpretation might overlook. These readings should remain open to correction and debate.

This is a browser-based prototype: you can add, edit, delete, filter and rearrange entries. Changes are saved locally on this device; there is no shared database or login. This edition provides forty works with sources and provisional counter-readings. All entries remain editable.
